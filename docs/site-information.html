Project and scientific content

DEMOCRESP is an ERC Starting Grant research project led by Dr. Fabian Habersack at the Department of Political Science, University of Innsbruck, Austria.

For questions about the project or the content of this website, contact fabian.habersack@uibk.ac.at.

Website data and privacy

This website contains no analytics, advertising, contact forms or embedded third-party media. Its own code does not set cookies or use browser storage. Fonts, images and scripts are served with the website.

GitHub Pages is the intended hosting service. When the website is served by GitHub Pages, GitHub may process technical request data, including IP addresses, to provide and secure the service. See the GitHub General Privacy Statement for information about GitHub’s processing of personal data.

Contact links open your email application. Following a link to another website takes you to a service with its own privacy practices.

Research participation

This project website does not collect research responses. Any future survey or study will provide its own participant information and consent materials.

Accessibility and corrections

If you encounter an accessibility issue or notice an error, please email the principal investigator with the page and a brief description.
