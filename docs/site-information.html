Website data and privacy

This website contains no advertising, contact forms or embedded third-party media. Fonts, images and the website’s own scripts are served locally. We use GoatCounter for visitor statistics, as described below.

GitHub Pages hosts this website. GitHub may process technical request data, including IP addresses, to provide and secure the service. See the GitHub General Privacy Statement for details.

Visitor statistics

We use GoatCounter to understand use of this website through aggregated traffic statistics. Measurements include page views, referring websites, approximate location, browser and operating system, language and screen width. GoatCounter does not use tracking cookies or persistent cross-site identifiers.

GoatCounter temporarily processes IP addresses and browser information in memory for up to eight hours to distinguish repeat visits. It does not store raw IP addresses in its analytics database. The service is operated by Martin Tournoij in Ireland and stores data in Finland and Germany. See GoatCounter’s privacy policy for details.

Our integration respects the browser’s Do Not Track and Global Privacy Control signals: when either is enabled, the analytics script is not loaded. You can also exclude your browser using GoatCounter’s browser-exclusion instructions. This optional preference uses browser storage to remember your choice.

Contact links open your email application. Following a link to another website takes you to a service with its own privacy practices.

Research participation

This project website does not collect research responses. Any future survey or study will provide its own participant information and consent materials.
